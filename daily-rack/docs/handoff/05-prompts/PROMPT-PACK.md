# Prompt pack
These are reusable, normalized handoff prompts. They preserve the chosen direction and product constraints; they are not a tool transcript or a promise of pixel-identical regeneration. The PNG files are the delivered visual record.

## UI overview
Create a high-fidelity five-screen mobile American mahjong UI overview for the working name Daily Rack: Today, Rack, Result, Clip and Game Night. Use warm ivory #FAF7F0, forest #173F36, magenta #99028F, pale sage cards, ivory tiles, green felt and pale wood. Editorial serif headings, clean sans-serif controls, consistent safe areas, practical touch targets and restrained shadows. Show flat complete artboards, not perspective hardware.

The product loop is guest Rack -> Result -> Clip. Today is a returning-player dashboard. Game Night and Learn are later P1 destinations. Do not reproduce the annual card. Reveal community choices only after a user submits.

Rack: choose a section, select exactly three of thirteen unique tile instances, and submit. The selected fixture state is ten remaining tiles plus three in the pass tray. Result: "Your pass" beside "One strong pass", per-tile reasoning, independent split bars and "Make my clip". Clip: a 9:16 overhead preview, magenta hook on white, all-caps white captions on #1B4F9C, optional 20-second voiceover, Share clip and Save video. Game Night: three date options, time zone, four RSVP rows, invite and variant help.

Use real legible short copy, no casino imagery, no invented league branding and no authentication wall. Percentages and sample suggestions are illustrative.
